# Claim 2 limitations and deviations

This is a faithful multi-step test of the exact particle recurrence, but it is
finite evidence in `d=2` for one smooth energy. It does not prove convergence
for every locally Lipschitz energy, every initialization, every parameter
choice, or the mean-field theorem. It uses a quadratic energy so consensus
behavior can be isolated from quadrature error and multimodal-target effects.
The already accepted full 2D mixture benchmark remains the separate Claim 5
regression.
